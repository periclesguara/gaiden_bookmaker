# Run Collection Module

## Entrada oficial

1. abrir a raiz do sistema
2. escolher `Collection`
3. cadastrar metadata
4. cadastrar itens em ordem
5. enviar HTML de cada item
6. rodar preparação
7. rodar normalize
8. rodar merge
9. revisar e fazer handoff

## Regras operacionais

- mínimo 2 itens
- máximo 10 itens
- ordem contínua
- sem duplicata
- uploads apenas em HTML
- storage canônico em `data/collections/`

## Verificações

- status da collection
- status por item: upload, prep, normalize, merge
- `manifest.json`
