Title: Reorganize Gaiden into four system blocks

OVERVIEW
This update officially reorganizes Gaiden into 4 functional blocks, with Block 02 defined as the system core and Block 03 isolated as the editorial/assets layer.

OFFICIAL SYSTEM BLOCKS
1. Block 01 - Entry
   - registration
   - source upload
   - input preparation

2. Block 02 - Core
   - normalize
   - fix / heading cleaner path
   - chunks
   - translate
   - split by chapter
   - refine
   - polish

3. Block 03 - Editorial and Assets
   - frontispiece
   - copyright
   - about this book
   - preface
   - introduction
   - epilogue
   - images
   - cover

4. Block 04 - Finalization
   - final assembly
   - EPUB export
   - PDF export

MAIN DELIVERY
- Block 02 is now explicitly declared as the textual core.
- The UI now reflects the 4-block architecture.
- Editorial content is separated from the textual core.
- Finalization is gated by editorial readiness and final MD availability.
- Editorial structure is prepared across 6 languages.

SUPPORTED EDITORIAL LANGUAGES
- EN
- PT-BR
- ES
- DE
- IT
- FR

EDITORIAL RULES IMPLEMENTED
Mandatory per language:
- frontispiece
- copyright
- about_this_book

Optional per language:
- preface
- introduction
- epilogue

Optional behavior:
- if enabled and filled, include in final build
- if enabled and empty, skip with friendly warning
- if disabled, ignore silently

CORE ISOLATION
Block 02 now carries explicit language isolation metadata for:
- EN
- PTBR
- ES
- DE
- IT
- FR

This supports the official direction of isolated execution by language and avoids cross-language context leakage at the orchestration level.

UI / UX CHANGES
- Navigation renamed to the 4 official blocks.
- Edition steps page now exposes block status clearly.
- Block 02 is highlighted as the official core.
- Block 03 shows editorial readiness by language.
- Frontmatter editing now clearly separates:
  - frontmatter
  - preface
  - introduction
  - epilogue
- HTML lane now clearly routes from Block 01 into Blocks 02-04.

BUILD / FLOW CHANGES
- Block 04 is blocked until:
  - Block 03 mandatory editorial content is ready for the selected language
  - BOOK.MD_FINAL exists
- This applies to:
  - build
  - export_epub
  - export_pdf
  - epubcheck
  - gaiden final assembly
