# Collection Storage Root

- storage canônico da Collection: `data/collections/<collection_code>/<language>/`
- autoridade de path: `gaiden/infrastructure/collections_storage.py`
- uploads entram apenas em `uploads/`
- prepared entra em `prepared/`
- normalized por item entra em `normalized_items/`
- source unificado entra em `merged/`
- `web/data` é proibido como storage primário da Collection
- `data/raw/book_XXXX` é proibido na entrada da Collection
