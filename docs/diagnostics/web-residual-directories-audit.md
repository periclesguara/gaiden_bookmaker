# Web Residual Directories Audit

Date: 2026-04-08

## Encontrado

- `web/Holmes`
- `web/When`
- `web/re`

## Classificação

- `web/Holmes`: resíduo / sem contrato operacional identificado
- `web/When`: resíduo / sem contrato operacional identificado
- `web/re`: resíduo / sem contrato operacional identificado

## Decisão

- esses diretórios não fazem parte da arquitetura oficial do portal
- novo código não deve depender deles
- permanecem como passivo estrutural até remoção controlada ou confirmação de uso legítimo
